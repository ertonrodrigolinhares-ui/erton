# Agentes Agency para o Claude Code

Instala no seu PC os 282 agentes do projeto [agency-agents](https://github.com/msitarzewski/agency-agents)
(licença MIT), para usar no **Claude Code**. Eles não mudam nada no Jarvis.

- **Instalar ou atualizar:** dois cliques em `Instalar agentes Agency.bat`.
- **Remover:** dois cliques em `Remover agentes Agency.bat` (tira só esses; os seus agentes continuam).

Os agentes vão para `%USERPROFILE%\.claude\agents\agency`, separados por divisão, e valem em todos os
projetos. Depois de instalar, feche e abra o Claude Code e peça pelo nome
(ex.: "use o agente Code Reviewer") ou digite `@` e escolha na lista.

A versão baixada é fixa (veja `VERSAO` em `instalar_agency.ps1`) para não entrar no seu PC nada que
não tenha sido conferido. Os agentes são em inglês e seguem regras dos EUA (impostos, leis).
